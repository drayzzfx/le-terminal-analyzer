Dark text field; border focuses to glacial-blue with a soft ring. Set `mono` for numeric entry (prices, tickers).

```jsx
<Input label="Symbole" placeholder="BTC/USD" />
<Input label="Montant" mono prefix="$" defaultValue="10 000" />
```

Props: `label`, `placeholder`, `mono` (tabular numerals), `prefix` (leading icon/glyph), `disabled`.
