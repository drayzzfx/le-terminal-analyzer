Small uppercase mono status pill — market direction, live signals, tags.

```jsx
<Badge tone="bull" dot>Long</Badge>
<Badge tone="bear">−8.1%</Badge>
<Badge tone="accent" dot>Live</Badge>
<Badge tone="mute">FX</Badge>
```

Tones: `bull | bear | neutral` (market), `accent` (glacial), `mute` (bordered grey). Set `dot` for a glowing status indicator.
